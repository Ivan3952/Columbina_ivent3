# Columbina combined site assets

Это общий архив по всем 4 частям.

## Внутри

- data.js — общий файл данных для сайта
- img/works/*.webp — все работы, переименованные по общему порядку 001–308
- columbina_all_works_summary.csv — сводная таблица
- combined_stats.json — статистика обработки

## Как поставить на сайт

1. Загрузи/замени папку `img/works/` в репозитории.
2. Замени текущий `data.js` на `data.js` из этого архива.
3. Commit changes.
4. Обнови сайт.

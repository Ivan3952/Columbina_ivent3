# Moon Maiden — сайт итогов

## Структура

Главная:
- обложка ивента
- кнопка «Итоги»
- музыка

После кнопки «Итоги»:
- Работы победителей
- Все работы участников

Оценка:
- одна оценка по 10-балльной шкале
- без комментариев

## Как добавить музыку

Положи файл:

audio/theme.mp3

Важно: браузеры часто блокируют автозапуск звука. Сайт попробует включить музыку сразу, но если браузер запретит — музыка включится после первого клика пользователя.

## Как добавить работы

Открой data.js и добавь объект в WORKS:

{
  id: 3,
  username: "@username",
  title: "Название или короткое описание",
  image: "img/works/username.webp",
  postLink: "https://t.me/...",
  score: 9,
  reward: 2500,
  isWinner: true,
  place: 1
}

Если работа не победитель:

isWinner: false,
place: null

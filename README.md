# Fix: winners pagination + remove credits

## Что изменено

1. Вкладка `Credits` убрана из верхнего меню.
2. Route `?page=credits` больше не используется и перекидывается на `results`.
3. Вкладка победителей теперь тоже с пагинацией.
4. Победители показываются по 12 работ на страницу.

## Как поставить

1. Замени `index.html` на файл из архива.
2. Полностью замени `script.js` на файл из архива.
3. Убедись, что в index.html подключено:

<script src="script.js?v=5"></script>

Если хочешь показывать меньше победителей на странице, в script.js поменяй:

var WINNERS_PER_PAGE = 12;

например на:

var WINNERS_PER_PAGE = 8;
